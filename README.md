# DATA DETECTIVE｜數據偵探社

生成式 AI 課程專案：以可追溯的統計 Wiki、Evidence Cards 和互動式 HTML 簡報，教學五種常見數據陷阱。

## 目前狀態

Phase 2：SRC-01～SRC-07 已獲核准並分三批 Ingest；Wiki 已有七份獨立來源及五案初步知識覆蓋。SRC-07 僅使用已核對的表格與公式，詳見 `wiki/log.md`。Graph、教學大綱、網站與最終測試尚未實作。

## 教學案件

1. 消失的 Y 軸：誤導性圖表。
2. 百萬年薪的公司：平均數與中位數。
3. 九成民意的真相：抽樣偏差。
4. 冰淇淋疑雲：相關與因果。
5. 逆轉的勝負：辛普森悖論。

## 預定目錄

- `raw/`：核准後取得的原始資料及擷取紀錄。
- `wiki/`：統計概念、來源索引與查詢紀錄。
- `cards/`：Evidence Cards。
- `cases/`：明確標示的模擬資料及計算規格。
- `drafts/`：核准大綱後的逐頁稿。
- `checks/`：可重複執行的驗證程序。
- `test-results/`：真實執行與檢查紀錄。
- `.agents/workflows/`：Graph 規格。
- `site/`：待開發的靜態 HTML 網站。
