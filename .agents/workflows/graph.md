# DATA DETECTIVE｜Workflow Graph V1（規格草案）

## Loop 契約

- **Goal：** 將核准來源轉為可追溯 Wiki、證據卡、14 頁統計教學及可測試的靜態網站。
- **Constraints：** 正式統計主張只使用成功 Ingest 的範圍；模擬數據另標示；不捏造來源與測試；節點只改表列產物。
- **Definition of Done：** 至少五份獨立來源、五案與追溯鏈、確定性數值驗算、互動及響應式驗收、真實紀錄、人工審核均通過。公開部署另需授權。
- **Trigger：** 上游產物完成、節點驗收失敗，或人工審核提出修改。
- **Stop Conditions：** 文獻／大綱未核准、來源不足、未解決的知識衝突、修正輪數超限、必需檢查無法執行。
- **重試上限：** 單頁局部修正最多 2 輪；主要流程回退最多 3 輪；人工關卡不自動重試。

## 節點、權限與回退

表中「讀」是允許輸入，「寫」是唯一可修改的產物；所有節點均不得改動已驗證的 `raw/` 快照。Validator 僅寫檢查結果，不能自行修正證據；Renderer 不能改寫統計結論。

| ID／名稱 | 任務；讀 → 寫 | 驗收條件 | 失敗回退／重試 |
|---|---|---|---|
| N01 Source Discovery | 搜尋獨立資料；需求、公開資料 → `sources.md` 候選欄 | 7–8 份候選可辨識來源與範圍 | 本節點續查；最多 3 輪 |
| N02 Human Source Approval | 人工確認；候選表 → 核准狀態 | 使用者明確核准 Source ID | 停止等待；不自動重試 |
| N03 Batch Ingest | 擷取核准原文；核准表、官方原頁 → `raw/`、`wiki/log.md` | 原文可取得、完整性與指定範圍可核對；批次 1–2 份起 | 回 N01 換候選或重查取得方式；最多 3 輪 |
| N04 Wiki Construction | 整理概念；已核對 `raw/` → `wiki/concepts/`、索引 | 每個結論有 Source ID、範圍與適用條件 | 回 N03 核對原文；最多 3 輪 |
| N05 Coverage Validation | 評估五案；Wiki、案件規格 → `test-results/` 覆蓋表 | 五案均有可用概念，至少五份獨立來源 | 回 N01 或 N04；最多 3 輪 |
| N06 Wiki Retrieval | 依案件查詢；Wiki 索引、概念 → 查詢紀錄 | 命中已 Ingest 條目，不混入未核准內容 | 回 N04；最多 3 輪 |
| N07 Evidence Cards | 指定來源轉卡片；N06 結果、原文 → `cards/` | 來源、結論、限制、案例、檢查規則齊全 | 回本節點核對來源；最多 2 輪 |
| N08 Lesson Outline | 教學排序；案件規格、卡片 → `outline.md` | 8–15 張主要投影片，五案及總考核完整 | 回 N07 補證據或本節點修訂；最多 3 輪 |
| N09 Human Outline Approval | 人工確認頁次與評量；大綱 → 核准紀錄 | 使用者明確確認 | 停止等待；不自動重試 |
| N10 Slide Draft | 撰寫逐頁稿；核准大綱、卡片 → `drafts/` | 每個重要統計主張有 Evidence ID；模擬值明標 | 回 N07 或本節點；單頁最多 2 輪 |
| N11 Statistical & Fidelity Validation | 獨立驗算與追溯；逐頁稿、卡片、模擬資料 → `test-results/` | 數值、來源、推論限制全部通過 | 數值回 N10／案例計算；來源回 N07；推論回 N06；最多 3 輪 |
| N12 HTML Rendering | 將已驗證稿轉靜態網站；稿、檢查通過紀錄 → `site/` | 圖文與已驗證稿一致；沒有新統計結論 | 排版回本節點，內容偏差回 N10；單頁最多 2 輪 |
| N13 Rendering & Interaction Validation | 查畫面、功能及儲存；`site/` → `test-results/` | 導航、五案、測驗、手機／桌面、Local Storage 通過 | 排版／功能回 N12；最多 2 輪 |
| N14 Execution Logging | 彙整實際執行；各節點輸入輸出與測試 → `test-results/` | 每次失敗與重試有時間、原因和結果 | 缺紀錄回相應節點補實證；最多 3 輪 |
| N15 Delivery & Reflection | 比較 V1／V2 並交付；全部紀錄 → `report.md` | 真實 Before／After、風險、未解決問題及交付項齊全 | 回 N14；最多 3 輪；部署另待授權 |

## 錯誤路由

來源不足 → N01／N03；證據卡錯誤 → N07；統計數值錯誤 → N10 或模擬資料計算；推論錯誤 → N06；排版錯誤 → N12；互動錯誤 → 對應 N12 前端功能。不得為修正頁面而重寫已驗證原文。

## 驗證與 V1／V2 實驗

N11 以獨立程序核對成長率、平均數、中位數、樣本比例、各分組與整體成功率、方向逆轉、圖文一致，以及 Source／Concept／Evidence／Slide ID 與適用條件。N13 檢查頁數、問答解析、循序解鎖、自由複習、五種互動、測驗配分、徽章、認證、Local Storage 保存與重置、來源入口及桌面／手機溢出。

先實跑 V1 並保存實際錯誤；僅依觀察到的問題調整節點位置或回退路徑，標記 V2，重跑受影響的檢查。刻意注入的錯誤與自然錯誤分開記錄；沒有觀察到的錯誤不虛構。一次執行只支持該次比較，不推論長期錯誤率。

每筆執行紀錄至少包含 `Run ID、Workflow Version、Node ID、時間、檢查項、實際輸入／輸出位置、通過／失敗、錯誤類型、原因、修正方式、返回節點、重試次數、修正後結果`。需由獨立審查者只看成品與來源做內容忠實度審查；若無法安排，明列未完成。
