# EVID-05-02｜分組率的加權與逆轉

- Concept ID：STAT-05-02
- Source ID：SRC-07；〈如何設計滿足辛普森悖論的例子〉頁 64 起、表 1 與加權公式；`raw/SRC-07-sinica-simpson.pdf`
- 核心結論：整體比例是各組比例按分組人數加權後的結果，可能與各分組的比較方向不同。
- 適用條件：首頁表格與公式已核對；其他頁面不作本卡依據。不得將描述性逆轉當成因果效果。
- 常見誤解：整體比例等於各分組比例的簡單平均。
- 案件：CASE-05；客服資料為教學模擬。
- 必要計算：`整體率 = Σ(各組成功數) / Σ(各組總數)`；A 21/30=70%，B 81/110≈73.64%。
- 檢查規則：分組分子與分母相加須等於整體；方向逆轉須由獨立程序驗算。
